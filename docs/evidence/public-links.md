# 증빙

기술 포트폴리오의 주장과 연결되는 공개 가능한 기술 증빙 링크를 모아둔 색인입니다.
공개 링크가 있는 상세 페이지에는 관련 링크를 claim 근처에도 함께 배치합니다.

이 페이지에는 public technical reference만 둡니다. 수료증, 상장 이미지, Google Drive folder, private repository, 내부 문서 링크는 포함하지 않습니다.
