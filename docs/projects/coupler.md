# Coupler

2025.11 - Present

## 개요

React Native 제품을 1.0.0 초기 구현 이후 2.0.0까지 전환하고 운영 중인 개인 제품 개발 프로젝트입니다.

## 역할

- 개발총괄 / Software Engineer
- 모바일 앱, API, 관리자 웹, 공개 문서의 개발 기준과 릴리스 기준을 정리했습니다.

## 구현

- 관리자 웹 TypeScript 전환과 typecheck CI/migration guard로 유지보수 기준을 고정했습니다.
- 회원가입과 심사 흐름을 use case와 서버 응답 계약 중심으로 분리해 화면 분기 기준을 단일화했습니다.
- Admin/Mobile/API가 같은 심사 상태 기준을 쓰도록 제출/재제출 UX와 심사 목록 기준을 정리했습니다.
- v2.0.0 릴리스 기준점과 복구 기준을 문서로 고정했습니다.
