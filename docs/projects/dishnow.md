# Dishnow

2019.02 - 2019.12

## 개요

React Native, React, Node.js, MySQL, AWS 기반 사용자/사장님용 실시간 식당 예약 앱을 개발했습니다.

## 역할과 범위

- 개발자 3인, 기획자 4인, 디자이너 1인 팀으로 진행했습니다.
- 사용자 앱, 사장님 앱, 인증, 예약 흐름, push 알림 구현에 참여했습니다.

## 문제와 제약

사용자 앱의 식당 검색/예약 흐름과 사장님 앱의 예약 관리 흐름이 같은 예약 상태를 기준으로 동작해야 했습니다.

## 설계와 구현

예약 DB 테이블을 중심으로 예약 목록과 상태를 관리하고, 사용자 앱과 사장님 앱을 분리해 구현했습니다.

- 공통 소셜 로그인, JWT 인증, push 알림을 구현했습니다.
- 사용자 앱에서 반경 내 식당 검색/예약, 리뷰 작성, 계정 관리 기능을 구현했습니다.
- 사장님 앱에서 가게 정보와 예약을 관리하는 기능을 구현했습니다.
- 예약 DB 테이블에 저장된 예약 목록과 상태를 기준으로 사용자/사장님 화면의 예약 흐름을 연결했습니다.

## 검증과 지표

예약 DB 테이블의 예약 상태 데이터를 기준으로 push 알림 적용 전후의 예약 성공률을 비교했습니다.

## 결과

- Google Play와 App Store에 배포했습니다.
- 푸시 알림으로 예약 성공률을 35% 개선했습니다.
- 학생창업 활동에서 창업지원단 캠퍼스타운사업 우수상, 예비창업패키지 기술부문 2위, 제4회 청년창업리그 우수상을 수상했습니다.
