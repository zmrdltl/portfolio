# 지도 기반 소리 업로드/조회 사이트

2024.10 - 2024.11

## 개요

Java 17, Spring Boot, MySQL, Google Maps API 기반 위치별 소리 업로드/조회 API를 구현했습니다.

## 역할과 범위

고객 납품 프로젝트에서 위치별 소리 업로드/조회 API 구현을 담당했습니다.

## 문제와 제약

위치 기반으로 소리를 업로드하고 조회할 수 있는 API가 필요했으며, 고객 납품 프로젝트라 소스 저장소는 비공개로 유지해야 했습니다.

## 설계와 구현

- 로그인/회원가입 API를 구현했습니다.
- JWT 기반 인증을 구현했습니다.
- 프로필 API를 구현했습니다.
- 소리 업로드 API를 구현했습니다.
- 위치 기반 소리 조회 API를 구현했습니다.
- 청취 기록 API를 구현했습니다.
