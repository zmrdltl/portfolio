# Map-based Sound Upload Site

2024.10 - 2024.11

## Overview

Implemented APIs for uploading and viewing sounds by location using Java 17, Spring Boot, MySQL, and Google Maps API.

## Implementation

- Implemented login and sign-up APIs.
- Implemented JWT-based authentication.
- Implemented profile APIs.
- Implemented sound upload APIs.
- Implemented location-based sound lookup APIs.
- Implemented listening history APIs.
