제 핵심 배경은 platform/backend engineering입니다.

티맥스클라우드에서는 No-code 플랫폼에서 애플리케이션 설계 메타데이터를 DDL, SQL, Java 서비스 코드, 배포 산출물, 테스트 화면, 운영 기능으로 연결하는 작업을 수행했습니다.

GlueSQL 오픈소스 활동은 같은 방향을 보완합니다. SQL engine 내부 구조, Rust 기반 데이터 처리, storage 지원, 멘토링, 코드 리뷰 경험을 이어왔습니다.

최근의 개발 과정에서는 구현 품질뿐 아니라 문서화 품질도 중요하다고 봅니다. 요구사항, 책임 분리, 테스트 기준, 확장성 관점을 명확한 문서로 남겨 동료와 AI agent가 같은 기준으로 구현과 리뷰를 진행할 수 있게 하는 방향을 지향합니다.
