## 요약

플랫폼 백엔드에서 동시성 오류와 데이터 정합성 문제를 찾아 직접 수정하고, 재현 테스트와 실제 API·DB 동작으로 결과를 확인해 왔습니다. 정규 경력의 코드 생성 플랫폼과 Rust 서비스부터 오픈소스 SQL 엔진, 직접 운영하는 모바일 제품까지 같은 방식으로 문제를 해결했습니다.

## 대표 작업

### [ClumL · 외부 LLM API 호출량 제어 동시성 수정](experience/cluml.md)

**유형·기간:** 정규 경력 · 2025.03 - 2026.07

**역할:** Rust 백엔드 문제 분석·구현 및 회귀 검증

**핵심 변화:** 여러 LLM API 호출이 같은 예약 전 상태를 읽고 함께 통과해 호출 수와 토큰 예약량이 허용치를 넘던 동시성 경합을 수정했습니다.

**검증:** 같은 동시성 조건에서 처리 중 호출 수와 대기 중 토큰 예약량이 각각 허용치의 10배 이상까지 늘어나는 과다 예약을 재현하고, 수정 후 두 값이 각각의 허용치 이하로 유지되는지 확인했습니다.

**기술:** `Rust` · `동시성 제어` · `회귀 테스트`

### [티맥스클라우드 · 코드 생성 플랫폼의 배포 전 API 테스트 기능](experience/tmaxcloud.md)

**유형·기간:** 정규 경력 · 2021.10 - 2024.11

**역할:** React 테스트 화면, Java REST API, DB 스키마 설계·구현 및 검증

**핵심 변화:** UI에서 정의한 서비스를 Java API·SQL과 JAR로 만드는 플랫폼에, API를 배포하지 않고 호출해 응답과 DB 반영을 확인하는 테스트 화면을 구현했습니다.

**검증:** 잘못된 서비스 정의·요청·응답 형식과 DB 반영 오류를 한 차례 약 20분의 빌드·배포·확인 절차 없이 발견할 수 있게 했습니다.

**기술:** `Java` · `WebSocket` · `Tibero`

### [GlueSQL · DISTINCT 실행 의미 구현](opensource/gluesql.md)

**유형·기간:** 오픈소스 기여 · 2021.06 - 현재

**역할:** Rust SQL 엔진 기능 직접 구현 및 기여자 코드 리뷰

**핵심 변화:** `SELECT DISTINCT`가 일반 `SELECT`처럼 중복 결과를 반환하던 문제를 수정하고, 일반 조회와 집계 함수에 맞는 중복 제거를 각각 구현했습니다.

**검증:** 단일·복수 열 조회와 `COUNT`를 포함한 집계 함수에서 `DISTINCT` 결과를 회귀 테스트로 확인했습니다.

**기술:** `Rust` · `parser/AST` · `SQL executor`

### [Coupler · 모바일 소개팅 앱 개발총괄](projects/coupler.md)

**유형·기간:** 개인 제품 · 2024.07 - 현재

**역할:** React Native 앱·Express API·React 관리자 웹·MySQL DB의 개발 및 운영 총괄

**핵심 변화:** 앱과 관리자 웹이 심사 상태를 각자 추론하지 않고 API가 반환한 접근 상태를 따르도록 통일했습니다.

**검증:** API 응답 계약, 모바일 화면 분기, 관리자 심사 큐를 각각 회귀 테스트해 서버의 심사 상태가 앱 화면과 관리자 큐에서 각 테스트의 기대값과 일치하는지 확인했습니다.

**기술:** `React Native` · `TypeScript` · `MySQL`
