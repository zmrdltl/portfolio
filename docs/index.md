## 요약

플랫폼 백엔드에서 동시성 오류와 데이터 정합성 문제를 찾아 직접 수정하고, 재현 테스트와 실제 API·DB 동작으로 결과를 확인해 왔습니다. 정규 경력의 코드 생성 플랫폼과 Rust 서비스부터 오픈소스 SQL 엔진, 개발과 운영을 총괄한 모바일 제품까지 같은 방식으로 문제를 해결했습니다.

## 대표 작업

### [ClumL · 외부 LLM API 호출량 제어 동시성 수정](experience/cluml.md)

**유형·기간:** 정규 경력 · 2025.03 - 2026.07

**역할:** Rust 백엔드 문제 분석·구현 및 회귀 검증

**핵심 변화:** 여러 LLM API 호출이 같은 예약 전 상태를 읽고 함께 통과해 호출 수와 토큰 예약량이 허용치를 넘던 동시성 경합을 수정했습니다.

**검증:** 외부 LLM API 호출 전 동시 호출 수 한도와 토큰 예약 예산을 각각 테스트했습니다. 토큰 예산은 테스트 요청의 예약량을 기준으로 허용 요청 수로 환산했습니다. 수정 전 두 테스트에서 허용 요청 수의 10배 이상이 제한 검사를 통과했고, 수정 후 같은 동시성 조건에서 각 한도를 지켰습니다.

**기술:** `Rust` · `동시성 제어` · `회귀 테스트`

### [티맥스클라우드 · 코드 생성 플랫폼의 배포 전 API 테스트 기능](experience/tmaxcloud.md)

**유형·기간:** 정규 경력 · 2021.10 - 2024.11

**역할:** React 테스트 화면, Java REST API, DB 스키마 설계·구현 및 검증

**핵심 변화:** 코드 생성 플랫폼의 기존 임시 배포 환경을 활용해, 정식 배포 전에 생성 API의 응답과 실제 DB 반영을 확인하는 테스트 화면을 구현했습니다.

**검증:** 서비스 정의, 요청·응답 형식, DB 반영 문제를 한 차례 약 20분이 걸리던 빌드·정식 배포·확인 절차에 들어가기 전에 발견할 수 있게 했습니다.

**기술:** `Java` · `WebSocket` · `Tibero`

### [GlueSQL · DISTINCT 실행 의미 구현](opensource/gluesql.md)

**유형·기간:** 오픈소스 기여 · 2021.06 - 현재

**역할:** Rust SQL 엔진 기능 직접 구현 및 기여자 코드 리뷰

**핵심 변화:** `SELECT DISTINCT`가 중복 결과를 반환하던 문제를 고쳤습니다. `SELECT DISTINCT`는 조회 결과의 행을, `COUNT(DISTINCT col)` 같은 집계 함수는 입력값을 중복 제거하도록 구현했습니다.

**검증:** 단일·복수 열 조회와 `COUNT`를 포함한 집계 함수에서 `DISTINCT` 결과를 회귀 테스트로 확인했습니다.

**기술:** `Rust` · `parser/AST` · `SQL executor`

### [Coupler · 모바일 소개팅 앱 개발총괄](projects/coupler.md)

**유형·기간:** 개인 제품 · 2024.07 - 2026.09

**역할:** React Native 앱·Express API·React 관리자 웹·MySQL DB의 개발 및 운영 총괄

**핵심 변화:** 약 30개 항목을 요구하던 첫 가입 신청을 기본정보와 필수 프로필 중심으로 줄이고, 서버가 앱 화면에 필요한 심사 상태와 관리자 심사 큐를 판정하도록 바꿨습니다.

**검증:** 앱이 서버의 심사 상태에 맞는 화면을 열고, 관리자 심사 큐가 가입 심사와 프로필 수정을 구분하는지 회귀 테스트로 확인했습니다.

**기술:** `React Native` · `TypeScript` · `MySQL`
