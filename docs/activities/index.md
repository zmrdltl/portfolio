# 활동

이 페이지는 경력과 오픈소스 본문을 보조하는 공개 가능한 교육, 멘토링, 커뮤니티, 수상 이력을 정리합니다.

## 오픈소스 멘토링

- GlueSQL에서 2021년 멘티, 2022년 리드 멘티, 2023년 멘토로 활동했습니다.
- SQL engine 기능, AST Builder, Parquet storage, test suite 개선과 함께 contributor mentoring, PR review, issue 안내를 수행했습니다.
- 오픈소스 기여 본문은 [GlueSQL](../opensource/gluesql.md) 페이지에 두고, 여기에는 멘토링 이력만 요약합니다.

## 교육 및 커뮤니티 활동

- 네이버 커넥트 부스트캠프 5기에서 vanilla JavaScript 미션, 코드 리뷰, 릴레이 프로젝트를 수행했습니다.
- 삼성 SDS 2021 하계 알고리즘 캠프에서 2021.07.05 - 2021.07.30 동안 DP1/DP2, 그래프1/그래프2, 조합론, 정수론, 자료구조, 시간복잡도, 알고리즘기초 등 9개 트랙의 백준 문제 103개를 풀었습니다. 관련 후기는 [블로그](https://codecollector.tistory.com/1099)에 정리했습니다.

## 수상

- 오픈소스 컨트리뷰션 아카데미에서 GlueSQL 활동으로 2021년 정보통신산업진흥원장상 최우수상, 2022년 정보통신산업진흥원장상 최우수상, 2023년 정보통신산업진흥원장상 장려상을 수상했습니다.
- 학생창업 활동에서 창업지원단 캠퍼스타운사업 우수상(2019.02.26), 예비창업패키지 기술부문 2위(2019.06.01), 제4회 청년창업리그 우수상(2019.06.28)을 수상했습니다.
- LoL 악성 유저 검출 프로젝트로 졸업 프로젝트 장려상을 수상했습니다.
- 관련 내용은 [LoL 악성 유저 검출](../projects/lol-toxic-user.md) 페이지에 정리했습니다.
