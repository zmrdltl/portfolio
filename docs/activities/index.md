# 활동

이 페이지는 경력과 오픈소스 본문을 보조하는 공개 가능한 교육, 멘토링, 커뮤니티, 수상 이력을 정리합니다.

## 오픈소스 멘토링

- GlueSQL에서 2021년 멘티, 2022년 리드 멘티, 2023년 멘토로 활동했습니다.
- SQL engine 기능, AST Builder, Parquet storage, test suite 개선과 함께 contributor mentoring, PR review, issue 안내를 수행했습니다.
- 2023년에는 17명 대상 1:1 mentoring coffee chat을 4주간 진행했습니다.
- Rust project 기본 명령어, test 작성, GlueSQL SQL 실행 흐름, storage 구조, AST builder, function 구현 방향을 설명했습니다.
- 오픈소스 기여 본문은 [GlueSQL](../opensource/gluesql.md) 페이지에 두고, 여기에는 멘토링과 수상 이력만 요약합니다.
