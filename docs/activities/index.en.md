# Activities

This page summarizes public education, mentoring, community, and award history that supports the main work and open-source pages.

## Open-source mentoring

- Participated in GlueSQL as a mentee in 2021, lead mentee in 2022, and mentor in 2023.
- Worked on SQL engine features, AST Builder, Parquet storage, and test suite improvements while mentoring contributors, reviewing PRs, and guiding issues.
- In 2023, held 1:1 mentoring coffee chats with 17 contributors over 4 weeks.
- Explained Rust project commands, test writing, GlueSQL SQL execution flow, storage structure, AST builder, and function implementation directions.
- The main open-source contribution narrative stays on the [GlueSQL](../opensource/gluesql.md) page; this page summarizes mentoring and award history.

## Education and community activities

- Completed vanilla JavaScript missions, code reviews, and a relay project in Naver Connect Boostcamp 5.
- Solved 103 Baekjoon problems across nine tracks, including DP1/DP2, Graph1/Graph2, combinatorics, number theory, data structures, complexity, and algorithm fundamentals, during the Samsung SDS 2021 Summer Algorithm Camp from 2021-07-05 to 2021-07-30. The related write-up is available on the [blog](https://codecollector.tistory.com/1099).

Problem titles keep the original Baekjoon wording.
